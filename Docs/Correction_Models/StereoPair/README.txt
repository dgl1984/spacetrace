Stereo Pair uses separate left-source and right-source correction WAVs in each Heads folder. Each combines its original correction with the head's additional correction IR, retaining the original 180 ms length with a 40 ms tail fade. The final WAV response plots and matching text descriptions are in Docs/Correction_Plots/StereoPair. See Docs/MANUAL.md for the preparation method and each head's manifest.json for the separate calibration gains. Retained Tone Trace models describe earlier design stages; the WAV plots show the combined corrections used by SpaceTrace.
